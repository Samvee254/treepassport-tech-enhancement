# Existing TreePassport Workflow (as understood from research)

## Core concept
    Geo-Tag -> Track -> Monitor -> Report

## Known functionality
- Unique TreePassport ID per tree
- GPS coordinates
- Physical traceability tag
- Photographs over time
- Health / growth information
- Verification status
- Impact data / reporting

## What is NOT known to be part of the existing platform
(these are treated as open opportunities, not confirmed gaps)

- Explainable risk scoring / predictive monitoring
- Tamper-evident audit logging of record edits
- Role-based access control specifics
- Public interactive map with multi-field filtering
- On-demand automated report generation

## Note on sourcing
This description is based on TreePassport's own public description
("Geo-Tag - Track - Monitor - Report") and general research into
comparable tree geo-tagging/monitoring platforms. It is not based
on access to TreePassport's internal systems or source code.
